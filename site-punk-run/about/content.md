### What is Punk Run?
Punk Run is a cyberpunk-themed game made with pixel-art assets from <https://itch.io/c/2053292/cyberpunk-pixel-art>

### Why the name 'Punk Run'?
The game is named after the animation spritesheet for the main character (Punk_run.png).

![Punk_run.png](https://github.com/adam-lafontaine/CMS/raw/sm-current/site-punk-run/img/Punk_run.png)

### Why use free pixel-art?
There is no artistic talent on the team.  Only programming talent.  And 'free' is within budget.

### What is the game about?
So far just running, jumping and spawing random sprites on screen.  The rule is that only art from the above asset packs can be used.  Anything else is on the table.  Adding some incremental roguelite elements is a possibility.  Currently the project is in the prototype phase.  Game elements will be added and tested as the technology is created.

### What game engine?
There is no game engine talent on the team.  Only programming talent.  Development is done using old fashioned C++ with SDL3.  Flexibility is the priority for this project.

### What gaming platforms?
Basically any.  The code 'targets' [SDL3](https://wiki.libsdl.org/SDL3/FrontPage).  SDL supports several platforms.  Currently there are [prototypes](https://almostalwaysadam.itch.io/punk-run) available for Windows, Linux, and most web browsers.
