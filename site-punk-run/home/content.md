## Controls

| Gameplay Controls | Gamepad | Keyboard  |
|-------------------|---------|-----------|
| Run / Stop        | A       | A / Enter |
| Jump              | Y       | Y / Space |
| Bat Sprite        | X       | X         |
| Cycle Theme       | B       | B         |

| Camera Controls | Gamepad | Keyboard    |
|-----------------|---------|-------------|
| Move Right      | Right   | Right Arrow |
| Move Left       | Left    | Left Arrow  |
| Move Up         | Up      | Up Arrow    |
| Move Down       | Down    | Down Arrow
